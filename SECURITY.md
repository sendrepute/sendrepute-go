# Security

Report vulnerabilities privately to support@sendrepute.com with affected
version, impact and a redacted reproduction. Never include keys, customer
messages or personal information. Coordinate disclosure before publishing
exploit details. No response-time SLA is promised. Version 0.1.x is supported.

Keep keys server-side, use verified HTTPS and explicitly trusted origins.
Paid analysis requires consent; the client never automatically retries.
Choose and test application failure policy rather than interpreting transport
or authentication errors as spam decisions.
